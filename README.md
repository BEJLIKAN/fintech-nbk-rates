## Запуск
Проверено на Python 3.12.14. Распакуйте весь проект, откройте терминал в этой папке.
Установка зависимостей: `python -m pip install -r requirements.txt`.
Полный анализ одной командой: `python run.py`.
Результаты записываются в `results/reproduced`; исходные результаты Colab сохранены отдельно в `results/original` и не перезаписываются.
В Colab нужно сначала загрузить/клонировать весь репозиторий, перейти в его каталог, установить зависимости и выполнить `!python run.py`.
Ноутбуки в `notebooks` используют общий код `src`; их нужно выполнять по порядку из полного проекта.

## Данные и задача
120 месячных наблюдений 2016–2025. Цели — изменения ставок новых кредитов юрлицам и физлицам (включая ИП), в процентных пунктах. Это не фактическая доходность активов банка.
Источники: https://data.nationalbank.kz/ (кредитные ставки и базовая ставка), https://stat.gov.kz/ (ИПЦ).
Первичные ссылки на ИПЦ: https://stat.gov.kz/api/iblock/element/1550/file/ru/ и https://stat.gov.kz/api/iblock/element/14511/file/ru/ .
CSV находится в `data`. Дата — месяц наблюдения, не публикации. Первая разность за январь 2016 использует декабрь 2015 из исходной истории.

## Протокол
Train: 2016–2022 (84 месяца, после лагов 80), validation: январь 2023–июнь 2024 (18), test: июль 2024–декабрь 2025 (18). Перемешивания нет. 16 признаков используют t−2 и более раннюю историю. Симметричная/асимметричная OLS с HAC(3), нулевой прогноз и LightGBM с четырьмя конфигурациями, early stopping 50, seed 42. Выбор по validation RMSE. Параметры после просмотра теста не менялись при упаковке.
Повторный запуск служит проверкой совпадения, а не новой независимой тестовой выборкой.

## Исходные результаты
Выбраны zero_change для бизнеса и LightGBM для физлиц. Test RMSE: 0.31634 и 1.23424 п.п.; R²: −0.11956 и 0.03056. Высокая точность не достигнута. Wald p-value 0.58068 и 0.21634: недостаточно оснований отвергнуть равенство коэффициентов; это не доказательство равенства. SHAP объясняет прогнозы, не причинность. Денежный сценарий — эквивалент ошибки для условного объёма 1 млрд тенге, не прибыль.

## Ограничения и незакрытые требования
Период 2016–2025 короче требуемого 2010–2025: для полной базовой ставки нет сопоставимой истории до введения в 2015. Это требует согласования, а не считается автоматическим выполнением задания.
Группа физлиц включает ИП. Календарь публикаций и исторические версии данных не восстановлены. Обучающий декабрь 2022 мог быть недоступен на начало первой валидации; поэтому это ретроспективный эксперимент, не подтверждённый backtest в реальном времени. Период 2024–2025 уже рассматривался в предыдущей учебной работе. Всего 18 тестовых месяцев.
PSI исходного кода использует псевдосчётчики 0.5: при разных объёмах выборок возможен ненулевой PSI даже одинакового постоянного прогноза (0.05737 для zero_change). Это артефакт сглаживания, не дрейф. Расчёт сохранён ради воспроизведения; выводы по постоянному прогнозу делать нельзя.
Отчёт представлен в файле Fintech_Variant6_Report.docx. Перед сдачей необходимо проверить объём 5–7 страниц и соответствие отчёта актуальным результатам расчётов. Методологические ограничения исследования перечислены выше; наличие отчёта и воспроизводимого кода само по себе их не устраняет.

## Файлы
`src/features.py` — признаки; `src/train.py` — запуск обучения и OLS-функция; `src/metrics.py` — метрики и PSI; `scripts` — исполняемые этапы; `notebooks` — те же этапы интерактивно; `predict.py` и `model.pkl` — исходный сохранённый прогноз; `config.yaml` — исходные настройки. Модель загружается только из собственного доверенного файла.
`from predict import predict` принимает DataFrame той же структуры, отсортированную непрерывную месячную историю; первые четыре строки дают NaN из-за лагов. Для будущего месяца можно добавить строку с датой и пустыми текущими значениями, сохранив прошлую историю.
