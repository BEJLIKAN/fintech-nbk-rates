# Асимметричная реакция кредитных ставок на инфляцию в Казахстане
Учебный проект по дисциплине «Финтех».
Вариант №6: население и бизнес.
## Цель
Исследовать, различается ли реакция кредитных ставок
на рост и снижение инфляции для населения и бизнеса.
## Данные
Планируется использовать месячные данные:
- ставки по новым кредитам населению;
- ставки по новым кредитам бизнесу;
- инфляция;
- базовая ставка Национального банка Казахстана.
Источники: Национальный банк Казахстана и
Бюро национальной статистики.
Период исследования уточняется после проверки доступности данных.
## Целевая переменная
Месячное изменение кредитной ставки в процентных пунктах.
Для населения и бизнеса строятся отдельные модели.
## Этапы работы
1. Подготовка данных и исследовательский анализ.
2. Создание признаков и базовых регрессионных моделей.
3. Обучение и настройка модели градиентного бустинга.
4. Итоговая оценка, проверка асимметрии и интерпретация SHAP.
