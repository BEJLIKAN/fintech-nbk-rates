ЗАГРУЗКА В GITHUB
1. Распакуйте архив через правую кнопку мыши → Извлечь всё.
2. Откройте папку fintech-nbk-rates внутри распакованного архива.
3. На главной странице вашего репозитория нажмите Add file → Upload files.
4. Перетащите содержимое папки: src, data, notebooks, scripts, results и файлы README.md, requirements.txt, config.yaml, model.pkl, predict.py, run.py, VERIFICATION.txt, UPLOAD_GUIDE.txt, run_log.txt.
   Перетаскивайте содержимое, не внешнюю папку fintech-nbk-rates и не ZIP.
5. README.md будет обновлён. Напишите «Добавлены код и проверка воспроизводимости», нажмите Commit changes.
6. Старые четыре ноутбука в корне можно оставить как исходные версии Colab. Для повторного запуска используйте версии в notebooks, как указано в README.
7. Ссылка преподавателю остаётся прежней: https://github.com/BEJLIKAN/fintech-nbk-rates

Этот комплект решает техническую упаковку. Отдельный отчёт 5–7 страниц ещё требуется. Период и доступность данных остаются методологическими ограничениями.
